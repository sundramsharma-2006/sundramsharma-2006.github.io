Four steps, no surprises

Baseline first, then models, then checks, then a write-up. Each step is logged so a reviewer can repeat it.

  1. First

    Frame

    Define the question, the metric and a naive baseline that any model must beat.

  2. Second

    Split

    Split by customer or by time so the test set cannot leak into training.

  3. Third

    Test

    Fit models, add confidence intervals and compare against the baseline.

  4. Last

    Report

    Write what worked, what failed and what is still unknown, in the README.

A random split can flatter your model

Credora scored 0.755 on a random split and 0.73 when split by customer. The gap is the leakage.

From Netflix

Check on out-of-time data before you trust it

Churn AUC was 0.67, and 0.61 when tested out of time. That is the number I would quote.
